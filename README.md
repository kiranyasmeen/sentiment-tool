## 📖 About
An emotional intelligence API that analyzes hidden nuances, sarcasm, and emotional weight in textual data using advanced NLP models. Built for developers who need more than just "positive/negative" labels.

## ✨ Features
- 🧠 **Nuance Detection** — Goes beyond basic polarity
- 🎭 **Sarcasm Analysis** — Detects underlying intent
- 📈 **Emotional Mapping** — Visualizes the "vibe" of any text
- ⚡ **Real-time API** — Fast, lightweight, and scalable
