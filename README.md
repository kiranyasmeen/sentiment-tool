## 📖 About
An emotional intelligence API that analyzes hidden nuances and sarcasm in textual data using NLP. VibeCheck reads between the lines so you don't have to.

## ✨ Features
- 😊 **Positivity Score** — Gauge enthusiasm and optimism instantly
- 🎭 **Sarcasm Detection** — Identify irony that traditional tools miss
- 🔥 **Intensity Mapping** — Visualize emotional peaks across content
- 📈 **Sentiment Over Time** — Track mood shifts across conversations
